# Currículo

`luca-telini-crozara-cv.pdf` é o currículo em PDF que o botão "Baixar CV"
aponta. Ele foi gerado de `curriculo.html`, na raiz do projeto.

Para alterar o currículo:

1. Edite `curriculo.html`.
2. Abra no navegador e use **Imprimir → Salvar como PDF**
   (destino "Salvar como PDF", tamanho A4, margens "Padrão",
   marcar "Gráficos de plano de fundo").
3. Substitua o arquivo nesta pasta.

Detalhe importante: o CSS `assets/css/cv.css` já define `@page { margin: 16mm }`.
Ao gerar o PDF pelo navegador, deixe as margens em **Padrão** — se você
trocar por "Nenhuma" ou por um valor customizado no diálogo, o conteúdo
estoura para uma segunda página.
